# 0002 Internationalization

Status: implemented
Owner: JOD

## Problem
All text is English and hard-coded. Easel should be translatable and ship Polish and Ukrainian.

## Behavior
- Every user-visible string goes through gettext (`_()`; `N_()` in static tables). Menus (`menus.ui`), the `.desktop`
  file and the AppStream metadata are translatable too.
- Text domain `easel`; catalogs in `po/`; `meson install` installs `.mo` files to `share/locale`.
- The language follows the environment (`LANGUAGE`, `LANG`). Missing translations fall back to English.
- Developer override: `EASEL_LOCALEDIR` points at an alternative locale directory.
- Shipped catalogs: `pl`, `uk`. Names such as "Easel", file-format names (PNG, JPEG ...) and credits are not translated.
- Strings that contain numbers or names use full format strings (`"Save changes to “%s” before closing?"`), never concatenation.

## Acceptance criteria
- [x] `meson compile easel-pot` / `easel-update-po` regenerate `po/easel.pot` and update the `.po` files.
- [x] `meson install` puts `pl` and `uk` `.mo` files under `share/locale/*/LC_MESSAGES/easel.mo`.
- [x] Running with `LANGUAGE=pl` shows Polish menus, dialogs, tool names/hints, preferences; `LANGUAGE=uk` Ukrainian.
- [x] `desktop-file-validate` and `appstreamcli validate` still pass with the merged translations.
- [x] A test fails if a source file with translatable strings is missing from `po/POTFILES.in`
      (meson's `gettext` handles this via `xgettext`; `tools/check-i18n.sh` lists untranslated entries per language).

## Design notes
`po/POTFILES.in` lists C files, `data/menus.ui`, `.desktop` and `.metainfo.xml`. `i18n.merge_file` produces the
translated desktop and metainfo files. Language selection is GLib's/gettext's; no in-app language switch.

## Test plan
Automated: the validators; `tools/check-i18n.sh` (msgfmt --check, counts untranslated). Manual: run with
`LANGUAGE=pl` / `uk` and look at menus, dialogs, tooltips.

## Out of scope
In-app language chooser, right-to-left layout review, plural forms beyond the few used (none yet), translating the Help (docs/help.md) file.
